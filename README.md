## Технологии сайта

React 18 + Vite · Tailwind CSS 4 · Framer Motion · сборка в статику, деплой в Docker (nginx).

## Запуск

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # прод-сборка в dist/
```

Docker:

```bash
docker compose up -d --build
```
